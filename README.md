# 💰 Caixa Eletrônico em Linguagem C

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um programa de **Caixa Eletrônico utilizando a linguagem C**, com o objetivo de simular uma operação básica de saque bancário.

O sistema permite que o usuário informe o valor desejado para saque e realiza a verificação do saldo disponível. Em seguida, calcula automaticamente a quantidade de cédulas necessárias para compor o valor solicitado.

O projeto foi desenvolvido com foco na prática dos conceitos fundamentais de programação, especialmente estruturas condicionais, estruturas de repetição, operadores aritméticos e manipulação de variáveis.

## ⚙️ Funcionalidades

- Exibição do saldo disponível de R$ 2.000,00.
- Solicitação do valor desejado para saque.
- Verificação do saldo disponível.
- Validação de valores múltiplos de 5.
- Cálculo automático da quantidade de cédulas.
- Distribuição do saque em notas de R$ 100, R$ 50, R$ 20, R$ 10 e R$ 5.

## 💻 Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`
- Compilador GCC
- Ambiente de desenvolvimento GDB

## 🧠 Conceitos de programação aplicados

Durante o desenvolvimento, foram utilizados os seguintes conceitos:

- **Variáveis:** armazenamento do saldo, valor do saque e quantidade de cédulas.
- **Entrada e saída de dados:** utilização de `scanf()` e `printf()`.
- **Estrutura condicional:** utilização de `if` e `else if`.
- **Estrutura de repetição:** utilização de `while`.
- **Operadores aritméticos:** divisão (`/`) e resto da divisão (`%`).
- **Lógica de programação:** decomposição do valor solicitado em diferentes cédulas.

## ▶️ Como executar o projeto

1. Clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Entre na pasta do projeto.

3. Compile o arquivo utilizando o GCC:

```bash
gcc main.c -o caixa_eletronico
```

4. Execute o programa:

```bash
./caixa_eletronico
```
